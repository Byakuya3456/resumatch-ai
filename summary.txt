Paper 1: A Hybrid Resume Parser and Matcher using RegEx and NER

This paper proposes a hybrid model for resume parsing and matching that combines rule-based methods (RegEx) and a pre-trained transformer model (spaCy's NER). The goal is to extract key information like name, phone number, email, skills, and experience from resumes. The system then scores the resumes based on their cosine similarity to a given job description using SBERT for vectorization. The reported parsing accuracy is around 70%. The paper highlights the challenges of handling various resume formats and the limitations of purely rule-based or deep learning approaches.

Paper 2: Automated Resume Parsing and Ranking using Natural Language Processing

This paper presents a "Resume Parser and Ranker" application that uses NLP and heuristic calculations to rank resumes. It leverages Deep Learning for Named Entity Recognition (NER) and claims a 93% accuracy in information extraction. The system preprocesses resumes to handle different formats, extracts features, and then ranks candidates based on a scoring system. The paper emphasizes the time-saving benefits for recruiters and the ability to handle unstructured resume data effectively.

Paper 3: Improved Resume Parsing based on Contextual Meaning Extraction using BERT

This paper focuses on the limitations of word-matching techniques in resume parsing and proposes using BERT for contextual understanding. It argues that traditional methods fail to capture the semantic meaning of the text, leading to inaccurate classifications. By using BERT for vectorization, the system can better understand the context of the resume and provide more accurate parsing. The paper compares this approach with existing techniques and shows that the proposed method performs better in classifying resumes.

Paper 4: Resume Parser and Job Recommendation System using Machine Learning

This paper describes a system with two main components: a Resume Parser and a Job Recommender. The parser uses spaCy and PDFMiner to extract details from resumes. The extracted skills are then fed into the job recommender, which uses a Tf-Idf vectorizer and cosine similarity to recommend jobs from a dataset. The paper details the implementation of both components and their integration into a Flask-based web application.
